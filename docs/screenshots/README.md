# Desktop screenshots

These are unaltered captures of the RDataCraft v0.41 Mac desktop UI, using
synthetic teaching data from the project examples and synthetic pointwise-test
fixtures. They contain no private study data or connected AI account information.
The Windows build uses the same scientific workspace in its native desktop host;
these images do not claim to be Windows screenshots.

- `worksheet.jpg`: editable treatment observations and study navigation.
- `curve-fitting.jpg`: separate concentration-response fits for two series.
- `analysis-results.jpg`: fitted-curve parameters and uncertainty in columns.
- `xy-comparisons.jpg`: pointwise significance labels and comparison settings.

Figure size and screen zoom are demonstration choices. Numerical values are
illustrative, not experimental findings. To refresh these images, capture the
actual desktop UI with synthetic data, check for personal information and retain
legible text. Do not fabricate controls, results or unsupported platform claims.
