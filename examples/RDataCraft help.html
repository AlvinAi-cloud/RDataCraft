Getting started

Start with Create… → Data table, choose the table type, then paste measurements directly into the grid. Each study holds data tables, linked graph views, analyses and a figure layout.

  1. Name the study by clicking its title. Click a data table name in the navigator to rename it.
  2. Enter observations in Data table. Choose Analyze and select a method appropriate for your experimental design.
  3. Review the results and assumptions. Open Graph to format a figure, then export SVG, PDF or PNG.
  4. Save a .rdatacraft study to keep the data and settings. A figure export does not save the study.

Examples & analysis guide adds original teaching data as a separate table; your existing observations stay in place.

Paste data & choose a table type

Select the top-left destination cell and paste with Command-V on Mac or Ctrl-V on Windows. The grid expands within its 10,000-row / 50-column limit. Use the paste-with-headers option when the first copied row contains column names; otherwise paste measurements only. Undo reverses the paste. Click a column header to rename it.

  • Column: one group per column. For paired data, the same subject occupies the same row across columns.
  • XY: numeric X first, followed by Y series. Set the number of Y replicates when creating the table; replicate subcolumns belong to their series.
  • Grouped: two factor-label columns, then replicate measurement columns.
  • Contingency: category labels first, then nonnegative integer counts; enter observed zeros as 0.
  • Survival: Time, Status (1 = event, 0 = right-censored), Group.
  • Multiple variables: one sample per row, one variable per column; useful for PCA and custom R.

Blank measurements represent missing values. Their treatment depends on the analysis. Do not use a blank to represent a measured zero. Import also accepts CSV, TSV and supported Excel workbooks.

Choose an analysis & interpret P values

Choose the scientific question and experimental unit before selecting a test. Two independent groups can use Welch’s t test; matched subjects require a paired method. Ordinary one-way or two-way ANOVA assumes independent observations. Repeated-measures ANOVA and mixed-effects designs require a suitable Advanced R script.

Inspect sample counts, effect estimates, confidence intervals, warnings and residuals alongside P values. A small P value does not measure effect size or establish the suitability of the model. Follow-up comparisons must account for multiplicity.

Graph formatting offers numeric P labels or significance stars. Numeric labels use four significant digits; values below 0.000001 display as P < 10⁻⁶. Stars use * for P ≤ 0.05, ** for P ≤ 0.01, *** for P ≤ 0.001 and **** for P ≤ 0.0001; ns indicates larger P values. Display choices do not change stored statistics.

Use Examples & analysis guide for a worked example and its assumptions.

Regression & curve fitting

Use an XY table, then choose a regression method in Analyze. Inspect the model equation and choose how replicates enter the fit. Fitting all observations and fitting means answer different weighting questions; do not treat repeated measurements as independent replicates.

To fit several Y series, set Fit series to All Y series — separate fit per group in Analysis, or use Fit every Y series independently under Figure settings → XY lines & fitted curves. Each group gets its own parameters and curve; these are not shared-parameter or global fits. Mean/error and shaded-band graphs can show the same fitted curves as scatter plots. Choose No connecting lines to hide point-to-point connections while retaining fitted curves. Show fitted curves and Show fitted mean 95% CI control those overlays separately. Error bars summarize observations at each X; a fitted confidence band describes uncertainty in the model mean.

Review convergence, parameter intervals and a residuals view before interpreting a curve. A four-parameter dose-response fit needs positive concentrations and adequate coverage of both plateaus. Poorly identified parameters can be misleading even when a curve looks smooth.

XY tables also offer Pearson and Spearman correlation, descriptive statistics and area under the curve. Correlation tests association; a regression models Y versus X. Treatment comparisons across time or X must account for independent experimental units, matching and repeated measurements; use a suitable reviewed model in Advanced R.

For a formula, model family or dependency outside the presets, use Advanced R analysis and return coefficients, diagnostics and a figure. The app does not automatically establish that a selected model is scientifically appropriate.

Power & sample-size planning

Use Power analysis in the top toolbar beside Figure layout; Advanced R is next to it. Select a design, then calculate required sample size or power at a chosen N. Use anticipated effects from scientific requirements or independent pilot information, not a post-hoc observed P value.

Two independent means assumes equal group sizes and a common population SD; it does not calculate Welch-test power. Enter Cohen d = mean difference / common SD. Paired designs use dz = mean within-pair difference / SD of within-pair differences; N is complete pairs. ANOVA uses balanced independent groups and Cohen f. Two proportions uses a normal approximation, not an exact test.

Required N is rounded up and achieved power is recalculated at that integer. Dropout inflates recruitment; it does not change analyzable N. For paired designs, the dropout assumption is loss of complete pairs. Check assumptions, independence and multiplicity. Use active table as pilot data to review estimates from a frozen snapshot of the current worksheet and selected analysis. Choose groups/populations and the outcome where offered. Fill planning inputs explicitly, then review and edit the anticipated effect before Calculate. Column t tests/ANOVA and two-category independent counts can prefill compatible designs. XY slopes/residual SD/correlation, grouped cell summaries, survival event fractions and multiple-variable summaries are supplied without substituting a different power test for unsupported models. Manual entry clears the pilot context and remains available. Export the planning CSV to retain final assumptions, pilot context and results; this calculator does not modify observations.

Transform observations & replace a whole table

Data table → Transform observations creates a new worksheet. Column tables can transform all groups or selected columns. XY defaults to all Y observations and replicates, preserving X; choose X only or X and Y explicitly when needed. Grouped tables preserve both factor columns. Multiple-variable tables require you to select measurements; leave numeric IDs and group codes unselected.

Log transforms require positive selected values. Z scores standardize each selected column independently. Percent-of-control uses a selected Column-table control mean. Count and survival tables have structural constraints and are not transformed here. Source observations and unselected cells remain unchanged.

Advanced: replace the entire table from text accepts a header row followed by CSV, tabs or semicolons. Select the delimiter if detection is unsuitable, then choose Replace. Read the inline result or validation error. Invalid text leaves the table unchanged; Undo restores a successful replacement. A graph display log axis does not change observations.

Principal component analysis (PCA)

Use Multiple variables: rows are samples and numeric measurement columns are variables. In PCA settings, select measurements explicitly and keep sample IDs and group labels as metadata. Choose centering/scaling and a missing-value policy deliberately.

Review explained variance, scores and loadings together. Group labels color points but do not enter the calculation. PCA is exploratory; apparent group separation is not a significance test.

Open Examples & analysis guide and select Principal component analysis (PCA) for the 12-sample walkthrough, three linked views and scaling/missing-data exercises.

Edit graphs, figure size & vector export

Click a graph title or axis label to edit its text. Click or double-click an axis or data series to open the corresponding formatting controls; the format toolbar provides the same options. Each linked view keeps its own settings. Delete unwanted views from the navigator after reviewing the confirmation.

New figures start at 3 × 3 inches with 7-point text and 200% screen zoom. Width and height control the exported canvas; zoom and Fit window change only its screen display. Physical screen inches depend on monitor scaling. Existing saved figure dimensions remain in effect.

Export SVG or PDF for editable vector artwork. The desktop apps provide Copy vector in PDF/SVG formats. Clipboard support depends on the receiving application; use SVG or PDF file export when direct paste is unavailable. Fonts must be available in the receiving application.

Figure layout arranges linked graph views into panels. Moving or resizing a panel changes the layout without changing source observations.

Import Prism files & review conversion

Choose Import and select .prism or .pzfx. Review the preview, selected source tables and conversion report before confirming. Supported multi-input analyses create separate editable result tables for each supported input.

Source observations, explicitly converted analyses and saved-result snapshots have different meanings. A saved result is a historical table; editing its source will not recompute a snapshot. Read each import report before using the imported analysis.

Unsupported binary graph formatting, analysis types and legacy .pzf files are not fully converted. Save .pzf as .pzfx or .prism in Prism first. Recreate unsupported graphs from imported observations and verify settings against the original.

Keep original Prism file preserves a byte-for-byte attachment within the study when size limits allow. It does not make all original content editable. Save original Prism file exports the preserved attachment.

Advanced R: scripts, packages & results

Advanced R analysis: beyond the presets

Write an R script or ask the AI Assistant to draft one. Review the code, data selection and scientific assumptions, then choose Run reviewed script. Drafting, loading and opening a study never execute its code.

  1. Open a data table, then choose Advanced R analysis at the end of the Analysis method menu, or use Advanced R in the top toolbar. Load a template or write your script. Opening Advanced R does not change the selected preset or run a script. data is a copied data frame with automatic numeric conversion; data_raw retains the original cell text. Column names stay unchanged.
  2. List any required packages, separated by commas. The app checks your bundled and personal R libraries. Choose Check / install packages to review missing packages and required dependencies from CRAN; installation starts only after Approve & install. The script does not run automatically afterward. stats supports GLMs and many methods beyond the presets. Compatible Mac/Windows binaries install into a library for your user account; bundled app packages and system R are unchanged. Source builds and non-CRAN repositories are not installed by this workflow.
  3. Assign result <- list(tables=list(Name=data.frame(...)), plot=my_plot, text="Interpretation"). plot can be a ggplot object or a function drawing a base R plot. Return up to ten nonempty tables, each within the 10,000-row / 50-column table limit. Large combined outputs are rejected.
  4. Run in a separate R process; Stop cancels it. The selected time limit is at most five minutes. Figures export as 3 × 3 inch SVG/PDF; use ggplot theme text size 7 for matching typography. Scripts can override their plot appearance.
  5. Save draft keeps code and an input snapshot in this study. Runs save code, the exact input copy, package versions, console, tables and figures. Save the study to retain these records. Loading a saved analysis lets you rerun its saved input or the active table; results are historical snapshots, not live linked analyses.
  6. Choose a returned table and Add result as data table to use normal graph/analysis tools. Importing results does not establish independence or validate the selected model. Review warnings, missing values, convergence and uncertainty.

Review code before running: custom R runs locally with your account permissions. The separate process protects the app session from ordinary errors; it is not an operating-system security sandbox. Do not run untrusted code.

Open examples/Advanced R teaching example.rdatacraft for original count and independent-group data with three saved drafts. No script runs when you open it.

Examples: the summary template returns means and SD; custom rank comparison returns a rank test and interval; the GLM template fits count responses while accounting for treatment and batch. Edit its formula and verify dispersion/design assumptions. Mixed-effects or other package methods become available after you approve installation of compatible packages. Stop can cancel downloading or staging; incomplete app-managed changes are rolled back. Approvals apply only to the displayed list and are never saved as blanket permission.

AI workflow: request an Advanced R script, review the proposed script in the assistant, choose Open in Advanced R, then review and run. The AI never executes the proposed script automatically.

Package installation recovery

Choose Check / install packages in Advanced R. Review the exact package list and destination, then Approve & install. Package installation and script execution are separate actions.

Stop cancels an app-managed installation and restores incomplete changes. After an app or computer crash, the next approved installation recovers a recorded transaction only when its owning process has ended. A live installer in another window is left alone.

If the app reports an unrecognized lock or an interrupted recovery, close all RDataCraft windows. Back up the personal library and any adjacent .rdatacraft-install-* folders before making changes. Do not delete backup folders during an unfinished promotion. Keep the installation log and request support or inspect the transaction before removing its lock.

Network failures: check your connection, retry Check / install packages and approve the fresh list. No compatible binary: the in-app workflow cannot build source packages or install from GitHub/Bioconductor. Use a suitable separately managed R environment for those methods.

The package library is per user, R version and platform. Installing an add-on does not update the packages used by the main app. Logs are available under Package installation log.

AI Assistant & data privacy

The assistant’s local tools work without a model. Open AI → Accounts and Models to connect your own ChatGPT account or an OpenAI, Claude, Gemini or compatible API service. Codex is not required. ChatGPT plan access depends on account eligibility and consent. Send shares your message, column names, graph settings and recent conversation. Table values and computed results are included only when Share active table values and computed results is checked. Review your data-sharing requirements before sending.

A model response is a proposal. Review the preview before applying supported changes to a new table copy. Advanced R proposals open as drafts; only Run reviewed script executes code. Missing packages require a separate Approve & install action.

Custom R and downloaded packages run with your account permissions. Process separation handles ordinary errors and Stop/time limits; it is not an operating-system security sandbox. Review code and its scientific assumptions before execution.

Choose a model in Accounts and Models and use Test connection without sharing study data. API services use your own key and may charge separately from website subscriptions. Saved connections are local to RDataCraft and excluded from projects. Disconnect for now retains them; Forget saved API connection removes the saved API key. Sign out selected account removes its ChatGPT session and attempts remote revocation. Offline graph and statistical workflows remain available.

Save, reopen & work in several windows

Save a .rdatacraft study to preserve tables, settings, linked views, layouts, imported-file reports and saved Advanced R records. Keep a separate backup before major edits. New study opens a separate desktop window on Mac and Windows, with its own analysis engine. The optional browser interface opens a separate workspace.

The desktop apps use native Open and Save dialogs. Save updates the current study; Save as creates another file. Closing an edited window offers Save, Don’t save or Cancel. In the optional browser interface, Save uses browser downloads; check the filename and location.

Advanced R results retain an input snapshot, code and package versions. Opening a study or loading a saved script never executes it. Use the saved snapshot to reproduce a run, or select the active table to run on current observations.

SVG/PDF/PNG exports contain the figure. CSV exports contain a table. These exports do not replace saving the complete study.

Troubleshooting & platform limits

Use the installer matching your computer: Intel Mac, Apple Silicon Mac or Windows x64. R and the required packages are bundled. Mac and Windows editions open in dedicated desktop windows. The Windows installer includes the Microsoft WebView2 component used to display the interface; it does not open an external browser.

If startup fails, Help → Show engine log opens the current window’s log. Each desktop window starts and stops its own local R engine. Close and reopen an affected window after saving available work.

Before reporting a problem, note the app version, operating system, action taken and full error. Prefer a small synthetic example. Review logs and studies for private observations or personal paths before sharing them publicly.

Development builds are not Apple-notarized or Windows code-signed. Platform validation and release status are documented with the download.
