Principal component analysis (PCA)

Which combinations of measurements explain variation among samples?

PCA summarizes multiple numeric variables with orthogonal components. This example centers and SD-scales measurements and keeps sample labels and group labels as metadata.

Try this: Add this example to open Analysis with 12 synthetic cell profiles and five selected measurements. Sample, Group and the numeric SampleID are metadata, not PCA variables. Three linked views show scores, loadings and explained variance.

Step-by-step analysis

  1. Inspect Data table: each row is one synthetic sample; CellArea, Intensity, Texture, Roundness and Signal are measurements on different scales. Do not transpose the table or include SampleID.
  2. In Analysis → PCA settings, confirm the five measurements, Sample as the label column, Group as the color column, and unit-SD scaling enabled. All 12 rows are complete; no imputation is performed.
  3. Read Explained variance first. PC1 accounts for the largest share of total centered/scaled variation; PC2 accounts for the largest remaining orthogonal share. The cumulative column shows how much the chosen components retain.
  4. Open the Scores linked graph: one point represents one sample. Nearby points have similar coordinates in the displayed components. Check axis percentages before assuming two components summarize the whole dataset. Enable sample labels to identify individual points.
  5. Open Loadings: arrow coordinates are eigenvector coefficients for each variable. Variables with similar directions contribute similarly to these components; opposite directions indicate opposite contributions. These coefficients are not variable–component correlations.
  6. Open Explained variance: bars show the individual component percentages and the line shows their cumulative sum. Select other component pairs in PCA settings if more structure needs inspection. Each linked view retains its own settings.
  7. Export Variance, Scores, Loadings and Preprocessing CSVs from Analysis. Export editable SVG/PDF from Graph, or add the three views to Figure layout. Save the study to retain the selected columns and preprocessing.

Try changing the analysis

  • Scaling exercise: in the Scores view, switch unit-SD scaling off and compare explained variance and loadings. Large-variance measurements can dominate an unscaled PCA. Restore scaling before comparing with the other linked views.
  • Missing-data exercise: clear one measurement in Data table. The default policy stops the analysis. Explicitly choose Exclude incomplete rows to use 11 samples; review the excluded-row note. Undo the cell edit and restore the default policy.
  • Metadata exercise: rename group labels or change their colors. Scores and explained variance should stay the same because groups do not enter the calculation. Editing a selected measurement should recompute them.

This dataset is invented for teaching, not biological evidence. PCA is exploratory and sensitive to scaling, outliers, batch effects and variable choice. Group separation is not a significance test or a validated classifier; do not report a PCA P value. Component signs are arbitrary, so mirrored plots from other software can represent the same solution.

Reference values for the supplied synthetic data

With all five measurements centered and SD-scaled, PC1 explains 89.7394% and PC2 8.7294% of variation; together they explain 98.4688%. All 12 samples are included. These percentages describe this invented dataset, not general biological expectations.
