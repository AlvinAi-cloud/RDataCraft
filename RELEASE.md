# RDataCraft v0.6 release

The user authorized review, upload on the existing **main** branch and a public
release generated by GitHub Actions. There is no additional development branch.
The source-only upload folder is `dist/RDataCraft-0.6-GitHub`.

Native platform validation builds Intel Mac, Apple Silicon, Windows x64 and Ubuntu
24.04 LTS amd64 installers. All four must pass source/installed-app checks before
release assembly. The Windows package test includes repeat installation and
uninstallation with study preservation. Ubuntu tests the installed read-only app,
its desktop bridge, graph/R results, native atomic save, independent panel controls,
engine cleanup, package reinstall and removal. Ubuntu R is installed via apt;
Mac and Windows bundle their engines. Its R 4.3 package library is compiled on
Ubuntu 24.04. Ubuntu source-package installation is not enabled in the app.

The release pipeline preserves the existing required Mac studio, multiwindow and
graph checks. Extended paste/planning UI sequences remain advisory; numerical and
server tests remain required. The local assistant-layout regression is separate
from those established release gates.

Every v0.6 installer and corresponding source record must match the same tested
commit and Actions run. The prior v0.5 Ubuntu-only reuse plan has been removed;
Intel Mac, Apple Silicon, Windows and Ubuntu are all rebuilt for v0.6. Assembly
rejects missing platforms, changed bytes, inconsistent provenance or missing
source records. Publication verifies uploaded names, sizes and SHA-256 digests
before publishing the tested tag. A failure leaves the release unpublished.

Stable installer names:

- `RDataCraft-macos-x86_64.dmg`
- `RDataCraft-macos-arm64.dmg`
- `RDataCraft-windows-x64-setup.exe`
- `RDataCraft-ubuntu-amd64.deb`

Mac disk images contain `RDataCraft.app`. Windows uses one stable installation
folder, uninstall entry and document registration. Ubuntu uses package name
`rdatacraft`, so package-manager installation replaces the prior package. Older
version-named Mac/Windows installations remain separate and can be removed after
checking the newer app. Updater links download installers; they do not replace
running files automatically or bypass operating-system installation controls.

Mac apps remain ad-hoc signed and not notarized; Windows setup is unsigned.
GitHub does not supply trusted signing credentials. The .deb is not a signed apt
repository. Users can verify it against the published release checksums.

Saved `.rdcraft` and legacy `.rdatacraft` studies remain supported. Existing schema
compatibility notes in WORKFLOWS.md apply. Corresponding R/package/Rust sources,
notices, build instructions, checksums and validation reports accompany the release.
System Ubuntu components remain managed by Ubuntu. Live provider eligibility and
vector paste into third-party design apps are outside automated certification.
